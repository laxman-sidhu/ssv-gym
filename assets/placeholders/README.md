# Placeholders

No photos are stored in this repository. Every image slot on the site shows a
designed placeholder until a photo link is set in the Google Sheet (uploaded to
Cloudinary from admin.html).

If you'd rather host a few photos on GitHub Pages, put optimised JPG or WebP
files here (under about 300 KB each) and use paths such as
`assets/placeholders/hero.jpg` in the sheet.

Add a 1200x630 `assets/og-image.jpg` for link previews on WhatsApp and social media.
